# Steam Sale Notifier

あなたが**すでに持っている** Steam のゲームがセールになったら、Discord に毎日お知らせするツールです。

Steam のウィッシュリストにはセール通知がありますが、**購入済みのゲームには通知が来ません**。
「遊んだことのあるゲームを人に紹介したい」とき、そのゲームのセールは絶好のタイミングなのに、知る手段がない——このツールはそれを解決します。

<!-- SCREENSHOT: Discord に届いたセール通知の例(ゲーム名・割引率・価格・ヘッダー画像が並んでいる様子) -->

## 特徴

- 毎朝 10 時すぎ(日本時間)に自動チェック。あなたのPCを起動しておく必要はありません(GitHub Actions 上で動作)
- **新しくセールが始まったもの・さらに値下げされたものだけ**を通知。同じセールを毎日通知したりはしません
- 初回だけは「現在セール中の一覧」をまとめて1回で通知(通知の洪水になりません)
- 必要なのは無料の GitHub アカウントと Discord だけ。サーバー代などは一切かかりません

## 必要なもの

- Steam アカウント(Steam Guard 有効)
- Discord(通知を受け取りたいサーバーの管理権限、またはチャンネルの Webhook 作成権限)
- GitHub アカウント(無料プランで十分)

## セットアップ

所要時間はおよそ15分です。上から順に進めてください。

### 1. Steam API キーを取得する

1. <https://steamcommunity.com/dev/apikey> を開く
2. Steam にログインする(Steam Guard の認証が必要です)
3. 「ドメイン名」欄には **任意の文字列でかまいません**(例: `localhost`)。⚠️ ここで悩む必要はありません — 何を入れても動作します
4. 表示された「キー」(英数字32文字)をメモする

> ⚠️ 「**アカウントにはSteamガードモバイル認証機器が必要です**」というエラーが出た場合、
> スマホアプリでの二段階認証がまだ有効になっていません(メールのSteamガードだけでは不十分です)。
> 次の手順で有効化してから、もう一度このページを開いてください。
>
> 1. スマホに **Steam Mobile** アプリを入れて、アカウント名とパスワードでサインインする
> 2. アプリ下部の「**Steamガード**」タブを開く
> 3. 「**認証機器を追加**」をタップし、案内に従って電話番号を登録する
>    - 💡 このタブにある「QRコードをスキャン」は、パソコンのログイン画面のQRを読むための別機能です。今回は使いません
>    - 💡 すでに30秒ごとに変わる5文字のコードが表示されているなら、モバイル認証は有効化済みです
> 4. 表示される「リカバリーコード」を必ずメモして保管する(スマホ紛失時に必要)
>
> また、Steam ストアでの購入実績がないアカウント(制限アカウント)は API キーを発行できません。

> ⚠️ この API キーは**パスワードと同じように扱ってください**。人に見せたり、チャットに貼ったりしないでください。

### 2. 自分の SteamID64 を確認する

1. Steam クライアントまたはブラウザで自分のプロフィールページを開く
2. プロフィールの URL を確認する
   - `https://steamcommunity.com/profiles/7656119…` の形式なら、末尾の **17桁の数字**が SteamID64 です
   - ⚠️ `https://steamcommunity.com/id/なまえ/` の形式(カスタムURL設定済み)の場合、数字が見えません。その場合は Steam クライアントの「設定 → インターフェイス →「WebブラウザのアドレスバーをURLを表示する」を有効化」するか、<https://steamdb.info/calculator/> に自分のプロフィールURLを貼ると SteamID64 が表示されます

<!-- SCREENSHOT: プロフィールURLのどこがSteamID64かを示した図(カスタムURLの場合の確認方法も) -->

> ℹ️ プロフィールを公開にする必要はありません。自分の API キーで自分のライブラリを見る構成のため、**非公開のままで動作します**。

### 3. Discord で Webhook を作成する

1. 通知を受け取りたい**チャンネル**の歯車アイコン(チャンネルの編集)を開く
   - ⚠️ **サーバー設定ではありません**。チャンネル名の横の歯車です
2. 「連携サービス」→「ウェブフック」を開く
3. 「新しいウェブフック」を押す
4. 名前(例: Steam セール通知)と投稿先チャンネルを確認する
5. 「ウェブフックURLをコピー」を押してメモする

<!-- SCREENSHOT: チャンネル設定 → 連携サービス → ウェブフック の画面 -->

> ⚠️ Webhook URL を知っている人は誰でもそのチャンネルに投稿できます。API キー同様、人に見せないでください。

### 4. このテンプレートから自分のリポジトリを作る

1. このリポジトリのページ右上の「**Use this template**」→「Create a new repository」を押す
2. リポジトリ名を付ける(例: `steam-sale-notifier`)
3. 可視性は「**Private**」を選ぶ(推奨)
   - 実行のたびに `state.json` へあなたの所有ゲーム一覧の一部が記録されるため、Private を推奨します
4. 「Create repository」を押す

> ℹ️ Fork ではなく「Use this template」を使ってください。Fork では定期実行が既定で無効になり、後から Private にもできません。

### 5. Secrets を登録する

1. 作ったリポジトリの「**Settings**」タブを開く
2. 左メニューの「**Secrets and variables**」→「**Actions**」を開く
   - ⚠️ すぐ隣に「Codespaces」「Dependabot」という似たページがあります。**必ず「Actions」**を選んでください
3. 「New repository secret」を押し、以下を **1つずつ** 登録する

| Name(この通りに入力) | Secret(値) | 必須 |
|---|---|---|
| `STEAM_API_KEY` | 手順1でメモした API キー | ○ |
| `STEAM_ID` | 手順2で確認した17桁の数字 | ○ |
| `DISCORD_WEBHOOK_URL` | 手順3でコピーした Webhook URL | ○ |
| `DISCORD_ERROR_WEBHOOK_URL` | エラー通知を別チャンネルに送りたい場合のみ(未設定なら上と同じ場所に届く) | － |

<!-- SCREENSHOT: Secrets and variables → Actions で3つのSecretが登録された状態 -->

### 6. Actions を有効化する

1. リポジトリの「**Actions**」タブを開く
2. 「I understand my workflows, go ahead and enable them」のボタンが表示されたら押す

### 7. 手動実行して動作を確認する

1. 「Actions」タブの左側から「**Daily sale check**」を選ぶ
2. 右側の「**Run workflow**」→ 緑の「Run workflow」ボタンを押す
3. 1〜3分待つ

**Discord に「✅ セットアップ完了。現在 N 本の所有ゲームがセール中です」と届けば成功です!** 🎉
明日からは毎朝、新しいセールだけが届きます。

<!-- SCREENSHOT: Run workflow ボタンの場所 -->

### 8. (推奨)GitHub の失敗メール通知をオフにする

失敗時は Discord にエラーが届く設計のため、GitHub からのメールは冗長です。

1. GitHub 右上の自分のアイコン →「Settings」を開く(リポジトリの Settings ではありません)
2. 「Notifications」を開く
3. 「Actions」の項目の「Email」のチェックを外す

## 設定のカスタマイズ(任意)

リポジトリの `config.yaml` を編集してコミットすると、次回実行から反映されます。

| 項目 | 既定値 | 説明 |
|---|---|---|
| `min_discount` | 20 | この割引率(%)未満のセールは通知しない |
| `max_notify` | 30 | 1回の実行で通知する最大件数(超過分は「他 N 件」と表示) |
| `country_code` | jp | 価格の国・通貨 |
| `language` | japanese | ストア情報の言語 |
| `first_run_summary` | true | 初回実行をサマリー形式にする |
| `request_interval_sec` | 1.2 | Steam への問い合わせ間隔(秒)。通常変更不要 |

## 通知のしくみ

- 通知されるのは「**新しくセールが始まった**」「**前回通知より割引率が上がった**」ゲームだけです
- セール継続中で割引率が変わらない日は通知されません(毎日同じ通知は届きません)
- 実行のたびに `state.json`(通知済みの記録)が自動でコミットされます。これは正常な動作です

## トラブルシューティング

### 「所有ゲーム一覧が空で返りました」というエラーになる

次のどちらかが原因です。

1. **STEAM_ID の間違い** — 17桁の数字(SteamID64)か確認してください。カスタムURLの文字列ではありません
2. **API キーと STEAM_ID が別人** — 登録した API キーは、その STEAM_ID 本人が取得したものである必要があります(他人のライブラリは、その人がプロフィールを公開していない限り見えません)

### 通知が来ない

- **セールが無いだけかもしれません** — Actions タブで最新の実行が緑(成功)なら、ツールは正常です。「セール中(20% 以上): 0 件」なら通知は送られません
- `min_discount` を下げると通知対象が増えます
- 一度通知したセールは、割引率が上がらない限り再通知されません
- Actions の実行自体が無いなら、次の「60日問題」を確認してください

### 実行が止まっている(60日問題)

GitHub は**60日間コミットのないリポジトリの定期実行を、通知なしで自動停止します**。
本ツールは毎日 `state.json` をコミットすることでこれを回避しており、通常は発生しません。
もし止まっていたら:

1. 「Actions」タブを開く
2. 「Daily sale check」に無効化のバナーが出ていれば「Enable workflow」を押す
3. 「Run workflow」で手動実行して復帰を確認する

### 「Workflow ファイルが無効」と表示される・スケジュール実行されない

`schedule` の `timezone:` 指定は比較的新しい機能です。お使いの環境で動作しない場合は、
`.github/workflows/daily.yml` の該当箇所をコメントの指示に従って UTC 表記(`'17 1 * * *'`)に書き換えてください。
