# Steam セール通知アプリ アップデート案内(友人向け)

通話で画面を見ながら説明する用のメモです。所要時間は約5分、ブラウザだけで終わります。
いまの設定(`config.yaml`)や通知の記録(`state.json`)は消えません。

## 口頭用の要点

- 何が変わる? → セール中のゲームを**全部**通知する(「他◯件」の省略がなくなる)
- なぜ手順が要る? → 「テンプレートから作ったコピー」なので、私の更新は自動では届かない
- どうする? → 最初の1回だけ「更新ボタン」を置く。以降はボタンを押すだけ
- 触ってはいけないもの → `config.yaml` と `state.json`(今回の手順では触らない)

## 【準備】更新ボタンを置く(最初の1回だけ)

1. 次のページを開き、右上の「コピー」のアイコン(□が2つ重なったマーク)を押して、中身を全部コピーする。
   https://github.com/HERO-Yuki/App_054/blob/master/.github/workflows/update.yml
2. 自分のリポジトリのページを開き、「Add file」→「Create new file」を押す。
3. 上の「ファイル名」の欄に、次をそのまま入力する(`/` を打つとフォルダに自動で分かれる)。
   `.github/workflows/update.yml`
4. 下の大きな枠に、1でコピーした中身を貼り付ける。
5. 右上の緑の「Commit changes…」→「Commit changes」を押す。

## 【更新する】

1. 自分のリポジトリの「Actions」タブを開く。
2. 左の一覧から「**Update from upstream**」を選ぶ。
3. 右側の「Run workflow」→ 緑の「Run workflow」を押す。
4. 1分ほどして、緑のチェック✓が付けば完了。
   (「すでに最新版です」と出たら、更新は不要という意味)

## 【動作確認】

1. Actions タブの「Daily sale check」を選び、「Run workflow」で1回動かす。
2. Discord に通知が届けば成功。

## うまくいかないとき

- 一覧に「Update from upstream」が出ない → ファイル名の入力ミスが多い。`.github/workflows/update.yml` の点と `/` の位置を確認する。
- 赤い✗が付いた → その画面のスクリーンショットを送ってもらう。失敗しても、いまの設定や記録は変更されない。
- 動作確認で通知が来ない → Settings → Secrets and variables → Actions に、`STEAM_API_KEY` / `STEAM_ID` / `DISCORD_WEBHOOK_URL` の3つがあるか確認する。

## 次回以降

「更新する」の4ステップだけ。

## 補足(自分用)

- 更新されるのは `src/` と `requirements.txt` だけ。`config.yaml`・`state.json`・他のワークフローは変更されない。
- 更新後のコードが動くか確認してからコミットされる。失敗したら何も変わらない。
- `.github/workflows/daily.yml` が変わる更新は、この仕組みでは届かない(GitHub の仕様)。そのときは手動で差し替えてもらう。
- 配布元(HERO-Yuki/App_054)を private にすると、この仕組みは動かなくなる。
- 友人のリポジトリの中身は未確認。古い構成なら `src` だけで足りない可能性がある。
