# 配布チェックリスト

## 配布前に自分(作者)がやること

### リポジトリの公開

- [ ] `LICENSE` の `[YOUR NAME]` を公開名義に置き換える
- [ ] GitHub に **Public** リポジトリを作成して push する(state.json は含めない)
- [ ] リポジトリの Settings → General → **「Template repository」にチェック**を入れる
      (これが無いと「Use this template」ボタンが出ない)

### 実環境での初回検証(自分のアカウントで一通り)

- [ ] 自分でも「Use this template」から Private リポジトリを作り、README **だけ**を見てセットアップが完了するか通しで確認する
- [ ] `timezone: 'Asia/Tokyo'` が受理されるか確認(Actions タブでスケジュールが認識されているか。
      ダメなら daily.yml のコメントに従い UTC 表記へ変更し、テンプレート側にも反映)
- [ ] 初回実行がサマリー形式で届くことを確認
- [ ] 翌日、変化がない場合に通知が来ないこと・state.json がコミットされていることを確認
- [ ] Secrets の `STEAM_ID` を一時的に壊して実行し、Discord にエラー通知が届くことを確認(確認後戻す)
- [ ] Actions のログに API キー・Webhook URL が出ていないことを目視確認
- [ ] README のスクリーンショット箇所(`<!-- SCREENSHOT: … -->`)を実画面で撮影して差し込む

## 友人にお願いすること

配布時に伝える内容。基本は「README の通りに進めて」で完結する想定。

1. **README のセットアップ手順(15分)を上から順に実施してもらう**
   - 必要なもの: Steam アカウント(Steam Guard 有効)/ Discord / GitHub アカウント(無料)
2. **リポジトリは Private で作ってもらう**(所有ゲーム一覧が state.json に入るため)
3. **Steam API キーと Webhook URL は誰にも(作者にも)見せない**よう伝える
   - セットアップを手伝う場合でも、キーの入力は必ず本人にやってもらう
4. セットアップ最後の「**Run workflow → Discord に届けば成功**」まで確認してもらう
5. 毎日リポジトリに `state.json 更新` のコミットが積まれるのは**正常動作**だと伝えておく
   (異常に見えて質問されがちなポイント)
6. 通知が来ない・エラーが届いたときは、まず README の**トラブルシューティング**を見てもらう
   - それでも解決しなければ、Actions の実行ログの URL を添えて連絡してもらう
7. (任意)通知が多すぎる/少なすぎると感じたら `config.yaml` の `min_discount` を調整してよいと伝える
